# СиАОД — алгоритмы сортировки

Учебный проект по дисциплине «Структуры и алгоритмы обработки данных» (СиАОД). В проекте реализованы внутренние и внешние алгоритмы сортировки на C++, а также подготовлены тесты и демонстрационная программа.

## Содержание проекта

Основная реализация алгоритмов находится в каталоге `SEMINARS_GREKOV`:

- `include/` — заголовочные файлы алгоритмов и общих функций для сортировки слиянием;
- `src/` — реализации алгоритмов;
- `SEMINARS_GREKOV.vcxproj` — проект Visual Studio с реализациями сортировок.

Дополнительные каталоги:

- `Tests/` — автоматические тесты алгоритмов в файле `test_all_sorts.cpp`;
- `Demo/` — демонстрационное приложение и входные/выходные данные для проверки внешних сортировок;
- `catch2/catch.hpp` — заголовочный файл библиотеки Catch2, используемой тестами;
- `Dementyanov_seminar.sln` — решение Visual Studio, объединяющее проекты.

## Реализованные алгоритмы

### Внутренняя сортировка

- Сортировка вставками — Insertion Sort;
- Бинарная сортировка вставками — Binary Insertion Sort;
- Сортировка выбором — Selection Sort;
- Обменная сортировка — Exchange Sort;
- Пузырьковая сортировка — Bubble Sort;
- Оптимизированная пузырьковая сортировка — Optimized Bubble Sort;
- Шейкерная сортировка — Shaker Sort;
- Сортировка Шелла — Shell Sort;
- Быстрая сортировка — Quick Sort.

### Внешняя сортировка

- Двухфазная сортировка простым слиянием — Two-Phase Merge Sort;
- Однофазная сортировка простым слиянием — One-Phase Merge Sort;
- Естественная сортировка слиянием — Natural Merge Sort.

Внешние алгоритмы используют временные файлы для распределения и слияния серий. Демонстрационные входные и выходные файлы находятся в `Demo/data/`.

## Требования

- Windows;
- Microsoft Visual Studio с установленной рабочей нагрузкой **Разработка классических приложений на C++**;
- поддержка стандарта C++17 или новее, если используется `std::filesystem`;
- библиотека Catch2 уже включена в репозиторий в виде заголовочного файла.

## Сборка проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `Dementyanov_seminar.sln` в Visual Studio.
3. Выберите конфигурацию сборки, например `Debug` или `Release`, и платформу `x64`.
4. В меню **Сборка** выберите **Собрать решение**.
5. Для запуска выберите нужный проект в качестве запускаемого:
   - `Demo` — демонстрация работы сортировок;
   - `Tests` — запуск автоматических тестов.

Если сборка не проходит, проверьте, что установлен компонент MSVC для C++, выбранная версия Visual Studio поддерживает используемый стандарт C++, а пути к проектам и файлам соответствуют структуре репозитория.

## Запуск тестов

1. Соберите решение.
2. Выберите проект `Tests` и запустите его (`Ctrl + F5` или **Отладка → Начать без отладки**).
3. Проверьте итоговый отчёт Catch2: он должен показывать количество успешно пройденных и проваленных проверок.

Тесты предназначены для проверки корректности сортировок на наборах данных, заданных в `Tests/test_all_sorts.cpp`. При добавлении нового алгоритма следует подключить его заголовок и включить алгоритм в общий набор тестов.

## Демонстрация внешней сортировки

Проект `Demo` содержит демонстрационную программу (`Demo/main.cpp`) и наборы данных в `Demo/data/`, включая входные файлы и ожидаемые результаты для трёх вариантов внешней сортировки.

При запуске из Visual Studio учитывайте рабочий каталог приложения: если программа использует относительные пути, он должен быть настроен так, чтобы каталог `Demo/data/` находился по ожидаемому пути. Для больших наборов данных выполнение может занять заметное время и потребовать дополнительного места на диске для временных файлов.

## Организация кода

- Заголовочные файлы в `SEMINARS_GREKOV/include/` объявляют алгоритмы и содержат общие вспомогательные функции.
- Файлы в `SEMINARS_GREKOV/src/` содержат реализации алгоритмов.
- `Tests/test_all_sorts.cpp` объединяет проверки алгоритмов.
- `Demo/main.cpp` предназначен для демонстрации работы программы на подготовленных данных.

## Примечание для GitHub

В репозитории желательно хранить исходный код, конфигурации проектов, тесты и необходимые небольшие тестовые данные.
